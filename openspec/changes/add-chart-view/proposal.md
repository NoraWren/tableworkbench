# Proposal

## 对应需求

- R-VIZ-01：分组图表（柱状、条形、折线、饼）。
- R-VIZ-02：分组上限与“其他”。
- R-VIZ-03：跟随筛选与只读。
- R-VIZ-04：深色模式与可读性。

## Why

现在能看数的只有表格和透视表。透视表适合交叉核对，但“哪个区最高、哪个渠道在涨”这类问题，用户得在表里逐行比数字。演示视频里也缺一个一眼能看懂的画面。

## What Changes

- 工具栏加“图表”按钮，弹出配置：分组列、度量列、聚合、图表类型。
- 四种图：柱状图、条形图、折线图、饼图，全部用 SwiftUI Canvas 画。
- 默认取前 12 个分组，其余合并成“其他”。
- 图表占满结果区，顶部显示标题、分组数与耗时，可“返回数据”。
- 图表跟随当前筛选；0 行时给提示。

## Capabilities

### New Capabilities

- chart-view：分组聚合的图形呈现。

### Modified Capabilities

- export-scope：不改行为，只是结果区多了一种内容类型。

## Impact

- DuckDBKit 增加 ChartSpec 与 ChartData，聚合复用现有 pivot 查询。
- Features 增加 runChart 与图表状态。
- App 增加图表配置面板与 Canvas 渲染视图。

## 性能与只读

分组聚合就是一条 GROUP BY，328 万行五组在 0.2 秒量级。图上只画 13 个点，绘制成本可以忽略。查询走只读通道，不写源文件。

## 不做什么

- 不做仪表盘、不做自由拖拽画布、不做双轴、不做图表导出图片。
- 不引入 Swift Charts 之外的第三方库，也不为图表加新的查询通道。
