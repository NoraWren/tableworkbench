# Proposal

## 对应需求

- R-GRID-07：双击任意行弹出侧边面板，纵向列出该行所有列的值，长文本完整展示，可复制。

## Why

表格按列展示，字段一多就要横向滚动才能看全一行，长文本还会被截断。排查一条脏数据时，用户最想要的是“把这一行竖过来看”。这是分析器该有的能力，也容易录进演示。

## What Changes

- 表格支持双击行，弹出一个面板，按“列名 / 值”竖排显示当前行的全部列。
- 空值显示为 (空)，长文本完整换行显示。
- 面板底部提供“复制这一行”，按 TSV 两列写进剪贴板。
- 只取这一行，不整表遍历。

## Capabilities

### New Capabilities

- row-detail：单行详情面板。

### Modified Capabilities

无。openspec/specs 尚未归档。

## Impact

- DataGrid：双击行回传行号。
- Features：WorkspaceModel 增加取一行数据的入口与状态。
- App：新增行详情面板。

## 性能与只读

取一行用现有的按块查询，只读，不扫描全表。2000 列的表只取当前显示列，避免一次拉两千个字段。

## 不做什么

- 不做行内跳转、不做上一行/下一行导航。
- 不做编辑。
