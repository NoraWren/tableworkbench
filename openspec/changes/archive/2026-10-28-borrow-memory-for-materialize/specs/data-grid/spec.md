# Spec Delta

## Purpose

给 `data-grid` 补两条大表上的行为契约：千万行设一个等值筛选的等待上限，以及大表排序后行序必须与 SQL 直算一致。单元格渲染、分块取数、列数上限这些不变。

## ADDED Requirements

### Requirement: 大表筛选的等待上限

在 1000 万行、20 列的表上设置一个等值筛选条件，从提交条件到顶部显示结果行数 SHALL 不超过 1 秒（M 系列或更新、Apple 内建 SSD）。

#### Scenario: 千万行按城市筛选
- **WHEN** 用户在 10m.parquet 上把「城市」设为等于上海
- **THEN** 1 秒内表格显示 1,267,600 行的首屏，顶部行数与之一致

#### Scenario: 清除筛选
- **WHEN** 用户清掉这个条件
- **THEN** 表格回到全量行数，不残留筛选结果

### Requirement: 大表排序的顺序保证

按数值列排序后，表格行序 SHALL 与同一条 SQL 直算的顺序一致，跨块滚动 SHALL NOT 出现重复或漏行。排序进行期间界面 SHALL 显示排序中的状态，SHALL NOT 显示上一次排序结果冒充新结果。

#### Scenario: 千万行按金额排序后滚到深处
- **WHEN** 用户在 1012 万行的表上按金额升序排序，然后滚到第 100 块
- **THEN** 每一块内的金额单调不减，块与块之间也连续

#### Scenario: 排序期间再点另一列
- **WHEN** 排序还没结束时用户点了另一个列头
- **THEN** 界面只呈现最后一次排序的结果，不出现两次结果混排
