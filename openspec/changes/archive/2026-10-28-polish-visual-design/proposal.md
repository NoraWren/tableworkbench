# Proposal

## Why

第一屏印象是开源项目的全部。现在空状态就是一行浅灰图标加两句说明，侧栏文件条目是纯文字堆叠，检查器的类型名用普通小字——功能都在，但没有一点"这东西值得转发"的观感。用户 2026-10-28 明确提了要更美观点。

## What Changes

- 空状态重做成居中卡片式：强调色渐变的圆形底、更清晰的字号层级、一行快捷键提示（⌘O 打开 / ⌘J SQL / ⇧⌘E 导出），保留"数据不出本机"这行。
- 侧栏文件条目加类型图标与基线对齐，行高略放宽。
- 检查器里列的类型名改成等宽胶囊标签，和列名形成主次。
- 只改视觉，不动交互、不动文案语义。

## 需求编号

R-SHELL-04（空状态与引导）、R-SHELL-03（深色模式与外观）、R-GRID-03（行列渲染的可读性）。

## 不做什么

- 不动图表配色。`ChartPalette` 的颜色是按 R-VIZ-04 的对比度规格（主色 6.6:1、次级 4.6:1）算出来并带测试的，为了好看改色会直接破坏无障碍约束。
- 不动表头自绘。`GridHeaderView` 的横向坐标是跨视图换算出来的，改样式容易带出列错位。
- 不引入设计系统或第三方 UI 库，全部用系统语义色与材质。

## 性能与只读

纯 SwiftUI 静态视图改动，不新增查询，不影响滚动与打开预算。深色模式下颜色全部走系统语义色，避免出现固定色值在深色下对比度不足。
