# Spec Delta

## Purpose

把「排序期间再点另一列」的行为写清楚：界面只呈现最后一次请求的结果，中间的请求不排队物化。分块取数、首屏预览、列数上限不变。

## ADDED Requirements

### Requirement: 连点列头只保留最后一次

排序或筛选还没结束时再次触发，界面 SHALL 只呈现最后一次请求的结果。被覆盖的中间请求 SHALL NOT 逐个执行物化。已经在执行的那一次 SHALL 允许跑完，界面在此期间 SHALL 保持「排序中」状态。

#### Scenario: 千万行连点四次
- **WHEN** 用户在 1012 万行的表上 1.5 秒内点四次同一个数值列头
- **THEN** 实际发生的物化是两次（第一次与最后一次），最终表格呈现最后一次请求的排序方向

#### Scenario: 排序中换另一列
- **WHEN** 排序进行中用户点了另一个列头
- **THEN** 界面不会先闪出中间那次排序的结果，只在最后一面呈现新列的顺序
