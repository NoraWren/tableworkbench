## ADDED Requirements

### Requirement: 展示态跟随当前文件

中栏展示的分析结果、图表和 SQL 结果 SHALL 只属于当前选中的文件。关闭文件或切换到另一个文件后，上一份的这些结果 MUST NOT 继续显示，中栏按新的状态走：没有文件时是拖放区，有文件时是数据网格。

正在进行的分析、建图与查询标记 SHALL 在关闭文件时一并清除。

#### Scenario: 关掉正在看一键分析的文件
- **WHEN** 对一份数据跑完一键分析，再执行「文件 > 关闭文件」
- **THEN** 侧栏显示「还没有打开文件」，中栏回到拖放区，不再出现任何图表

#### Scenario: 看图表时切换到另一个文件
- **WHEN** 停在 A 文件的一键分析结果页，点侧栏里的 B 文件
- **THEN** 中栏显示 B 文件的数据网格，A 的图表不再出现

#### Scenario: 看 SQL 结果时关掉文件
- **WHEN** SQL 抽屉返回了结果，然后关闭这个文件
- **THEN** SQL 结果区和中栏的结果都不再显示

#### Scenario: 分析跑到一半关掉文件
- **WHEN** 一键分析还在进行时关闭文件
- **THEN** 中栏不停留在「正在分析…」，直接回到空状态
