# Proposal

## Why

R-GRID-08 要求 3000 列的表能打开。现在视图只画前 200 列，但取块的 SQL 仍然把 3000 列全部 CAST 成文本再取回，界面上一次翻页要等十几秒，第二次打开文件时还会卡住。

## What Changes

- 取块接口增加"只取指定列"的版本，网格把当前显示的列传下去。
- 网格和取数共用同一份"可见列"计算，超过 2000 列时都只取前 200 列。
- 检查器的列清单给宽表加眼睛按钮，逐列启用或隐藏，默认前 200 列。
- 测试覆盖宽表只取显示列，且值不为 NULL。

## 需求

- R-GRID-08：3000 列的视图打开不卡死。

## 不做什么

- 不做列的批量启用/搜索，只支持逐列点眼睛按钮。
- 不改 Parquet 缓存和导入路径。

## 性能与只读

取块从 3000 列降到 200 列，查询宽度下降 93%，只读约束不变。
