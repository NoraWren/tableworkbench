# 手动验收清单

屏幕解锁后按顺序过一遍。每条都写清步骤、期望结果和对应的需求编号。

启动开发包：

    ./scripts/make-app-bundle.sh
    open build/TableWorkbench.app

测试数据：

    ./scripts/make-bench-data.sh

## 1. 打开与导入

| 步骤 | 期望 | 需求 |
|---|---|---|
| 拖入 bench-data/wide-100k.csv | 左栏出现文件，表格显示 100000 行 | R-IMP-01 |
| 拖入时窗口内圈出现强调色描边，拖出后消失 | 描边随拖拽出现和撤掉 | R-IMP-08 |
| 从浏览器拖一段网页文字进来 | 光标显示不可放置，不高亮，松手无反应 | R-IMP-08 |
| Command+O 选择多个 CSV | 每个都进左栏，第一个选中 | R-IMP-01 |
| 打开 gbk-sample.csv | 中文不乱码，编码显示 GB18030 | R-IMP-04 |
| 打开 sample-20mb.xlsx | 弹出工作表选择器，选“数据” | R-IMP-06 |
| 选择“汇总” | 只显示 2 列 1 行 | R-IMP-06 |
| 取消选择器 | 左栏不新增条目 | R-IMP-06 |
| 把一个 PNG 改名 csv 打开 | 弹出“看起来不是文本文件” | R-IMP-07 |
| 再次打开同一个 CSV | 左栏不重复，选中已有条目 | 去重 |

## 2. 表格

| 步骤 | 期望 | 需求 |
|---|---|---|
| 点“金额”列头 | 升序，列头出现 ↑ | R-GRID-04 |
| 再点两次 | 降序、恢复原顺序 | R-GRID-04 |
| Shift 点“区域” | 两列排序，列头出现 1、2 | R-GRID-04 |
| 工具栏“计算列”，输入 金额 - 成本 | 表格末尾多一列，值与 SQL 直算一致 | R-GRID-06 |
| 计算列输入 金额 * 不存在字段 | 底部提示“表达式无效”，不加空列 | R-GRID-06 |
| 横向滚动 | 行号固定在左侧 | R-GRID-03 |
| 滚到表尾 | 没有长时间空白，第 100 块很快 | R-GRID-02 |
| 选中 3 行 Command+C | 粘贴得到 3 行 TSV | R-EXP-04 |
| 关闭复制表头后再复制 | 没有表头行 | R-EXP-04 |

## 4. SQL

| 步骤 | 期望 | 需求 |
|---|---|---|
| 打开 SQL 抽屉，运行 SELECT * FROM data LIMIT 10 | 10 行结果 | R-SQL-01 |
| 运行按区域分组的金额求和 | 5 行，列名和耗时显示 | R-SQL-03 |
| 运行 DROP TABLE data | 提示只读，不执行 | R-SQL-02 |
| 运行 SELEC * FROM data | 显示原始错误和中文说明 | R-SQL-03 |
| 运行 CREATE TEMP TABLE t AS SELECT 1 AS a | 成功，随后能查 t | R-SQL-02 |
| 点“返回数据” | 回到表格 | R-SQL-03 |
| 在 SQL 抽屉点“存为片段”，输入名字region后保存 | 侧栏出现“SQL 片段 / region”，popover 关闭 | R-SQL-04 |
| 把编辑器内容改成别的语句，再点侧栏的 region | 编辑器填回片段语句，SQL 抽屉保持展开，不自动执行 | R-SQL-04 |
| 右键片段选“删除” | 侧栏不再显示该片段，存储里的数组变空 | R-SQL-04 |

## 7.5 多工作表与图表

| 步骤 | 期望 | 需求 |
|---|---|---|
| 打开多 sheet 的 xlsx | 弹出选择器，除“打开”外还有“全部导入（N 个工作表）” | R-IMP-06 |
| 点“全部导入” | 每个工作表单独进左栏，行数各自独立（sample.xlsx 出「数据」4 行与「汇总」1 行），重复点不新增条目 | R-IMP-06 |
| 工作表超过 20 张时点“全部导入” | 提示“工作表太多了”，左栏不新增（这一条造 21 张表的样本太费事，由测试程序覆盖） | R-IMP-06 |
| 双击任意一行 | 弹出详情面板，竖排列出全部字段，空值显示 (空) | R-GRID-07 |
| 点“复制这一行” | 粘贴得到“列名 值”两列文本 | R-GRID-07 |
| 工具栏“图表”，选 区域 + 金额 + 求和 | 出柱状图，五根柱，顶部有组数与耗时 | R-VIZ-01 |
| 依次切条形图、折线图、饼图 | 都能画出来，不崩 | R-VIZ-01 |
| 用“城市”分组 | 超过 12 组时只画 12 根加“其他”，纵轴不被“其他”压扁 | R-VIZ-02 |
| 先筛选 区域=华东 再建图 | 图上只剩华东 | R-VIZ-03 |
| 筛选到 0 行再建图 | 显示“没有匹配的数据”，不画空图 | R-VIZ-03 |
| 生成图后点“返回数据” | 回到表格，排序和筛选保持原样 | R-VIZ-01 |
| 点“一键分析” | 自动出 3–5 张图，页头写明挑了哪些列，订单号不在其中 | R-VIZ-05 |
| 一键分析后向下滚到底 | 每张图都带组数与耗时，最后一张能完整看到，不卡 | R-VIZ-05 |

## 8. 性能

用 Instruments 的 Core Animation 录 10 万行滚动，记录掉帧率。目标 60fps、掉帧低于 5%。这条不能用肉眼判断。

## 9. 菜单与快捷键

| 步骤 | 期望 | 需求 |
|---|---|---|
| 没打开文件时拉开「文件」和「查询」 | 只有「打开文件…」是黑字，导出、关闭文件、运行、新建查询、一键分析都置灰 | R-SHELL-02 |
| 打开一个 CSV 再看这两个菜单 | 导出、关闭文件、运行、新建查询恢复可点 | R-SHELL-02 |
| Shift+Command+E | 弹出导出面板，与点菜单同一回事 | R-SHELL-02 |
| Command+R | 运行 SQL 抽屉里的语句，结果进入查询结果区 | R-SHELL-02 |
| Command+N | SQL 抽屉展开，填好 SELECT * FROM data LIMIT 100 | R-SHELL-02 |
| Shift+Command+A | 走一键分析，出 3–5 张图 | R-SHELL-02 |
| Command+F | 弹出筛选面板，标题是「筛选条件」 | R-SHELL-02 |
| Control+Command+S | 侧栏折叠；再按一次展开 | R-SHELL-01 |
| Command+Option+I | 检查器收起；再按一次展开 | R-SHELL-01 |
| Command+J | SQL 抽屉开合 | R-SQL-01 |
| Command+. | 「查询 → 取消」始终灰着，v0.1 没有长查询可取消 | R-SHELL-02 |
| 按住 Option 打开「查询」菜单看快捷键提示 | 每项后面都写着组合键，与上表一致 | R-SHELL-02 |

收起侧栏后退出，重开应用，侧栏仍是收起的。

快捷键只按「点菜单」和「按键盘」两条路各验一次就够。别再往工具栏或 SQL 面板上补第二份 keyboardShortcut：同一组合注册两次时系统会静默丢掉一个，按不出反应也很难查。
