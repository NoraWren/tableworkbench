# 性能记录

每次提交前跑 scripts/bench.sh，把结果追加到下面的表。只追加，不改历史行。

机器口径：M1 或更新、16 GB 内存以上、Apple 内建 SSD。换机器要另起一节。

## 当前基线

2026-10-23，bootstrap-app-skeleton 第一版，release 构建。
机器：MacBookPro18,3（M1 Pro），16 GB，macOS 27.0.1，arm64。
数据：bench-data/500mb.csv，500.2 MB，3,282,000 行，20 列，UTF-8。
命令：./app/.build/release/TableWorkbenchBench bench-data/500mb.csv --json

## 说明

- 数字退化超过 10% 时，在提交说明里写原因和打算怎么办。
- 用缓存命中的结果填表时，在单元格里标"（缓存）"。
- 任何数字不许估，跑不出来就写"—"并说明为什么跑不出来。
- 调试构建的数字不记录，只记 release。
