# 08 性能

这一章是硬约束。任何功能实现如果过不了这里的数字，要么优化，要么砍掉，不允许"先跑通再说"。

## R-PERF-01 打开速度

- 优先级：P0
- 状态：进行中
- 行为：从松手到表格可滚动的时间上限。
- 验收：
  - [ ] 500 MB CSV 首次打开不超过 2 秒（不含后台转 Parquet 完成；实测 2.10–2.42 秒，未达标，取舍见 R-DEC-16）
  - [x] 同一个文件第二次打开不超过 1 秒（实测 0.79–0.84 秒）
  - [x] 1 GB Parquet 打开不超过 2 秒（实测 1.76 秒）
  - [ ] 1000 万行、20 列 Parquet 打开不超过 3 秒（7 次里 4 次达标，中位数 2.65 秒，最差 3.51 秒，见 R-DEC-17）
- 测量方法：脚本记录进程启动到首屏绘制的墙钟时间，输出为表格，纳入 bench.sh。
- 边界：冷启动不含在应用内打开文件，冷启动单独算，见 R-PERF-04。
- 依赖：R-IMP-05、R-PERF-05

## R-PERF-02 缓存转换耗时

- 优先级：P1
- 状态：已定义
- 行为：后台把 CSV 转 Parquet 的耗时，用户能继续用，但转换不能无限拖。
- 验收：
  - [ ] 500 MB CSV 转 Parquet 不超过 20 秒
  - [ ] 转换期间滚动和筛选仍然可用
  - [ ] 转换中退出应用不损坏源文件
- 边界：不做多线程分片转换，先单线程，够用就停。
- 依赖：R-IMP-05

## R-PERF-03 滚动与交互

- 优先级：P0
- 状态：已定义
- 行为：滚动和点击必须跟手。
- 验收：
  - [ ] 1000 万行垂直滚动稳定在 60 fps，掉帧率低于 5%
  - [ ] 100 列 × 1000 万行横向滚动不掉帧
  - [ ] 点击一行到选中态出现不超过 50 毫秒
- 测量方法：Instruments 的 Core Animation 和 Time Profiler，录屏计时作为交叉验证。
- 边界：不做逐帧打点上报。
- 依赖：R-GRID-01、R-GRID-02

## R-PERF-04 包体积与启动

- 优先级：P0
- 状态：已定义
- 行为：这两个数字直接写进 README 第一屏，必须诚实。
- 验收：
  - [x] dmg 不超过 30 MB（release 构建实测 15 MB）
  - [x] 解压后 app bundle 不超过 60 MB（release 构建实测 53 MB）
  - [ ] 冷启动到窗口可交互不超过 0.6 秒
- 说明：如果 DuckDB 静态链接后包体积超过 30 MB，先把目标调成 40 MB 并写进 README，不许隐藏。
- 边界：不为省体积裁剪 DuckDB 功能。
- 依赖：R-REL-01

## R-PERF-05 基准数据集

- 优先级：P0
- 状态：已定义
- 行为：scripts/make-bench-data.sh 生成固定数据集，所有人跑同样的数据。
- 数据集四份：
  - 500 MB CSV，约 800 万行，20 列，含中文、空值、日期。
  - 1 GB Parquet，由上一份转换而来。
  - 1000 万行 × 20 列 Parquet，用于滚动测试。
  - 20 MB xlsx，3 个工作表，含合并单元格和公式。
- 验收：
  - [ ] 脚本在空目录能一键生成全部四份
  - [ ] 生成的数据行数、列数、文件大小写进 bench.sh 的输出
  - [ ] 数据集不进 Git 仓库，加进 .gitignore
- 边界：不用真实用户数据做基准。
- 依赖：R-PERF-01

## R-PERF-06 内存

- 优先级：P1
- 状态：已定义
- 行为：打开大文件后的常驻内存要可预期。
- 验收：
  - [x] 打开 1 GB 文件后常驻内存不超过 1.5 GB（峰值 RSS 1.30 GB，常驻只会更低）
  - [ ] 连续打开关闭 20 个大文件，内存回到基线附近（允许 ±200 MB）
  - [ ] 不做任何操作放 30 分钟，内存不上涨
- 边界：不为省内存牺牲速度。
- 依赖：R-GRID-02、R-IMP-05

## R-PERF-07 基准记录

- 优先级：P1
- 状态：已定义
- 行为：每次提交前跑 bench.sh，结果追加到 docs/bench-history.md 一张表里，列包括日期、提交、机型、四个关键数字。
- 验收：
  - [ ] 新增记录不改历史行
  - [ ] 数字退化超过 10% 时能在表里一眼看到
- 边界：不在 CI 里跑，手动执行。
- 依赖：R-PERF-05
