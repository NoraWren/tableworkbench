# 01 产品范围

## R-SCOPE-01 定位

- 优先级：P0
- 状态：已定义
- 场景：开发者或做分析的人，手里有一个打不开的大 CSV，或者要看一份几百万行的导出文件。
- 行为：一个 Mac 应用，拖进文件就能看、能筛、能算，全程不联网。不做编辑，不做公式，不做协作。
- 一句话：给本地数据一个现代界面。
- 对外一句话：Excel 打开要三分钟的文件，这里 0.3 秒。
- 边界：不替代 Excel 的编辑能力，不替代 BI 平台的建模能力，不做云端。
- 依赖：R-GRID-01、R-PERF-01

## R-SCOPE-02 目标用户

- 优先级：P0
- 状态：已定义
- 行为：三类人优先，其余不作为设计依据。
  1. 要看别人导出的数据的开发者：日志导出、数据库 dump、埋点导出。
  2. 已经在用 DuckDB 或命令行、但想要界面的分析人员。
  3. 手上文件太大、Excel 打不开的运营和财务。
- 判断依据：前两类人会上 GitHub、会转发，是"挣名声"这个目标的主要受众。
- 边界：不为不写代码的办公用户做零门槛引导，不为企业 IT 做部署和权限方案。
- 依赖：R-SCOPE-05

## R-SCOPE-03 三个核心场景

- 优先级：P0
- 状态：已定义
- 行为：v0.1 只保证这三个场景顺，其他场景能用就行。
  1. **打开看一眼。** 从 Finder 拖一个几百 MB 的 CSV 到窗口，1 到 2 秒内看到数据，横向纵向都能滚。
  2. **按条件缩小。** 点列头排序，在工具栏写筛选条件，几百万行里挑出几千行，操作到出结果不超过 1 秒。
  3. **算一个数。** 写一段 SQL 或拖一个透视表，得到分组汇总，能导出成 CSV。
- 验收：
  - [ ] 三个场景各有不超过 30 秒的录屏，看的人不需要解释
- 边界：不覆盖"清洗数据""合并多个文件""做图表报告"这三件事。
- 依赖：R-IMP-01、R-GRID-02、R-SQL-01、R-PVT-01

## R-SCOPE-04 v0.1 功能清单

- 优先级：P0
- 状态：已定义
- 行为：以下功能全部实现才算 v0.1，额外功能一律进 v0.2 待办。
  - 打开 CSV、TSV、Parquet、xlsx（R-IMP-02）
  - 表格虚拟滚动、排序、筛选（R-GRID-02、R-GRID-04、R-GRID-05）
  - 列检查器：类型、空值、唯一值、分布（R-INSP-01）
  - SQL 抽屉，只读，可取消（R-SQL-01）
  - 拖拽透视表（R-PVT-01）
  - 导出 CSV 和 Parquet，复制选区（R-EXP-01、R-EXP-04）
- 边界：不做编辑、公式、多标签页、云同步、用户账号、插件系统。
- 依赖：R-MS-02

## R-SCOPE-05 对外叙事

- 优先级：P0
- 状态：已定义
- 场景：项目发到 Hacker News、X、V2EX 时，读者第一眼看到什么。
- 行为：README 第一屏只有四样东西，顺序固定。
  1. 一张 GIF，拖入文件到出数据，不超过 8 秒。
  2. 一句对比，带实测数字。
  3. 三个数字：打开耗时、包体积、冷启动时间。
  4. 一行安装命令或下载链接。
- 验收：
  - [ ] 第一屏没有架构图、目录说明、功能罗列
  - [ ] 三个数字与 `scripts/bench.sh` 的实测一致，并注明测试机型
- 边界：不写"基于 DuckDB 的高性能数据分析平台"这类空话。
- 依赖：R-REL-03

## R-SCOPE-06 明确不做（v0.1）

- 优先级：P0
- 状态：已定义
- 行为：以下能力即使有人在 issue 里要，也不在 v0.1 承诺。
  - 单元格编辑和公式计算
  - 多文件 join 的图形化向导（SQL 里能写，但不出向导界面）
  - 图表和仪表盘
  - Windows 和 Linux 版本
  - 云端同步、共享链接、账号体系
  - 插件或脚本扩展
  - AI 分析（v0.2 做，见 R-SCOPE-07）
- 原因：每一样都会让"三个月出能演示的版本"这个前提失效。
- 边界：不做承诺，但架构上不堵死，见 R-DEC-09。
- 依赖：R-MS-01

## R-SCOPE-07 AI 分析的阶段

- 优先级：P1
- 状态：已定义
- 行为：AI 分析（模型配置、自然语言问数、一键洞察、结果解释）是 v0.2 的第一个功能，v0.1 不包含。
- 理由：v0.1 的十二周已经排满。AI 要额外做配置界面、两种协议适配、上下文构造、敏感字段打码和只读校验，约三周。
- 边界：v0.1 的界面里不出现任何 AI 入口，避免用户看到一个点不动的按钮。
- 依赖：R-AI-01、R-MS-10
