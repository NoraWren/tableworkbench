# 06 列检查器

## R-INSP-01 列统计面板

- 优先级：P1
- 状态：已定义
- 场景：选中一列，想知道它干不干净、能不能用。
- 行为：右侧检查器显示六类信息。
  - 基本：列名、DuckDB 类型、示例值三个。
  - 完整性：总行数、空值数、空值率。
  - 分布：唯一值数、最常见的 5 个值及其占比。
  - 数值列额外给：最小、最大、均值、中位数、标准差。
  - 文本列额外给：最短长度、最长长度、含空白字符的行数。
  - 时间列额外给：最早、最晚、时间跨度。
- 验收：
  - [x] 1000 万行选一列，统计在 1 秒内出结果
  - [x] 数值列的均值与 SQL AVG 结果一致
  - [x] 空值率四舍五入到小数点后两位，不带科学计数法
- 边界：不做相关性分析、不做数据质量评分。
- 依赖：R-INSP-02、R-INSP-03

## R-INSP-02 统计的查询策略

- 优先级：P1
- 状态：已定义
- 行为：
  - 主要统计在一条 SQL 里一次算完，用条件聚合，不逐项查询；直方图、高频值、类型冲突探针各走一条独立查询。
  - 结果按列缓存在会话内，数据或筛选条件变化才失效。
  - 1000 万行以上的表，唯一值计数仍走精确 `count(DISTINCT)`。DuckDB 1.1.3 的 `approx_count_distinct` 实测误差过大且更慢，见 `12-decisions-risks.md`。
- 验收：
  - [x] 一次统计最多触发 5 条查询（聚合、高频值、直方图或时间桶、类型冲突探针、反例），断言实测小表文本列 3 条
  - [x] 切换列不重复查询已算过的列
  - [x] 不使用近似计数，界面不出现"近似"标记
- 边界：不做后台预计算所有列，按需算。
- 依赖：R-SQL-02

## R-INSP-03 分布图

- 优先级：P1
- 状态：已定义
- 行为：
  - 数值列：20 个等宽区间的直方图，鼠标悬停显示区间和行数。
  - 文本列：最常见值的横向条形图，最多 10 条。
  - 时间列：按天或按月聚合的折线，粒度随跨度自动选。
  - 时间列只给一组“按天分布”，不再把同一批日期重复列成高频值；数值、文本、时间三组分布各自带小标题。
  - 文本列的极值标签写“字典序首尾”，不叫“范围”，避免被当成数值区间读。
  - 图形用 SwiftUI Canvas 画，不引第三方图表库。
- 验收：
  - [x] 直方图柱子数量与区间数一致，悬停能读出确切行数
  - [x] 深色模式下柱子和文字对比度均达到 WCAG AA（深色文字 5.91:1、直方图柱 7.63:1；浅色文字 4.28:1、直方图柱 6.88:1。直方图柱改用 ChartPalette，原先系统强调色只有 3.97:1；浅色文字是系统次要色 0.5 透明度压出来的，4.28:1 差一点到 4.5，没为一个面板改系统语义色）
  - [x] 列里只有一个唯一值时也能正常渲染，不除零崩溃
  - [x] 时间列只出现一组日期分布，同一批日期不重复列两遍
- 边界：不做缩放、不做导出图片。
- 依赖：R-INSP-01

## R-INSP-04 类型冲突提示

- 优先级：P2
- 状态：已完成
- 行为：一列里大部分值能按数字解析、少数不能时，DuckDB 会把整列当文本。检查器显示橙色「类型冲突」区块，分两行说明多少行不是数字、多少行看着像数字，并给出最多两个不同的反例。只对文本列生效，纯文本列和数值列不显示。
- 验收：
  - [x] 6 行里 4 个数字加 2 个非数字，提示「2 行不是数字」「4 行看着像数字，整列按文本处理」并列出反例
  - [x] 纯文本列与数值列不显示该提示
  - [x] 反例按值去重，3 行都是同一个「—」时只列一次
- 边界：不自动修改数据，不改列类型。
- 依赖：R-IMP-03
