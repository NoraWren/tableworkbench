# 14 图表

透视表解决“交叉看数”，图表解决“一眼看出谁大谁小”。这一章只做聚合结果的图形呈现，不做仪表盘、不做自由拖拽画布。

## R-VIZ-01 分组图表

- 优先级：P1
- 状态：已定义
- 场景：用户想快速看出“各区金额谁最高”，不想在透视表里逐行比数字。
- 行为：
  - 工具栏“图表”按钮弹出配置：分组列、度量列、聚合方式、图表类型。
  - 图表类型四种：柱状图、条形图、折线图、饼图。
  - 分组列可选任意列；度量列只列数值列，聚合支持求和、计数、去重计数、平均、最小、最大。
  - 生成后占满结果区，顶部显示标题、分组数、耗时与“返回数据”。
  - 点“返回数据”回到表格，进入图表前的排序与筛选保持原样（实测：区域=华东 加两列排序，返回后仍是 100000 行中的 20000 行，两个列头排序序号都在）。
  - 图形用 SwiftUI Canvas 画，不引入第三方图表库。
- 验收：
  - [x] 区域 × 金额求和，柱状图五个柱，数值与 `GROUP BY 区域` 的 SQL 结果一致（测试程序比对通过）
  - [x] 切换条形图、折线图、饼图都能正常渲染，不崩（328 万行文件逐个看过）
  - [x] 生成一次 328 万行文件的分组图不超过 1 秒（release 构建透视 0.07 秒；之前测到的 1.15 秒是 debug 包，见 R-DEC-19）
- 边界：不做多维度交叉图、不做双轴、不做缩放。
- 依赖：R-PVT-01、R-INSP-03

## R-VIZ-02 分组上限与“其他”

- 优先级：P1
- 状态：已定义
- 行为：
  - 默认只画前 12 个分组，其余合并成“其他”，避免几百个柱挤在一起。
  - 柱状图与条形图按数值从大到小排；折线图按分组标签升序排，方便看时间趋势。
  - 分组只有一个时也能画，不除零。
- 验收：
  - [x] 城市列有 900 个取值时，图上 13 个柱（12 个 + 其他），其他等于剩余之和（900 行造数断言：13 个点，其他 = 剩余 888 项之和）
  - [x] 只有一个分组时柱高满格，标签居中（单分组断言：一个点、量级等于自身、饼图占比 100%，离屏截图 chart-single.png 确认柱满格）
- 边界：不提供“显示全部”开关，需要看全量直接看透视表。
- 依赖：R-VIZ-01

## R-VIZ-03 跟随筛选与只读

- 优先级：P1
- 状态：已定义
- 行为：
  - 图表基于当前视图计算，筛选后重新生成只统计筛选结果。
  - 查询只读，不改源文件、不写缓存以外的东西。
  - 结果行数为 0 时显示“没有匹配的数据”，不画空图。
- 验收：
  - [x] 先筛选区域=华东再生成图表，五个分组里只剩华东一个，数值等于筛选后求和（断言：筛选后只剩 1 个分组，总量等于筛选后 sum(amount)）
  - [x] 筛选到 0 行时提示没有数据（断言筛出不存在的城市得到空图；离屏截图 chart-empty.png 显示“没有匹配的数据”）
- 边界：不做图表导出为图片。
- 依赖：R-GRID-05

## R-VIZ-04 深色模式与可读性

- 优先级：P2
- 状态：已完成
- 行为：
  - 柱、线、饼的颜色跟随系统强调色，但会按当前画布色把明度推到对比度够用为止（ChartPalette），浅色和深色都不低于 4.5:1。
  - 主色与次级色（“其他”那根柱、饼图隔行扇区）之间留出明度差，饼图相邻扇区、色弱用户和黑白打印都分得开。
  - 饼图扇区描一道 1 像素画布色，首尾同色相接时边界仍然清楚。
  - 图表自己铺画布色，取色和渲染用同一个值，离屏量出来的对比度与真窗口一致。
  - 文字同样从系统次要色压成实色后再推，浅色下系统次要色原样画只有 3.84:1。
  - 数值超过一万时用千分位，小数保留到两位。
  - 标签过长时截断加省略号，完整值放在悬停提示里。
- 验收：
  - [x] 四种图在浅色与深色下逐张离屏渲染并量对比度：柱、折线、饼块 6.63–6.64:1，次级饼块/“其他”柱 4.59–4.62:1，图内文字 4.58:1（浅）/5.02:1（深），网格线 1.35:1（装饰，只求看得见）
  - [x] 主色与次级色在两种外观下都分得开（饼图相邻扇区与图例色块不是同一明度）
  - [x] 空结果与单分组两种边界都出图正常（chart-empty.png、chart-single.png）
  - [x] 12,345.6789 显示为 12,345.68（ChartData.format 断言）
- 边界：不做自定义配色。
- 依赖：R-VIZ-01

## R-VIZ-05 一键分析

- 优先级：P1
- 状态：已定义
- 场景：第一次打开一张表，不知道先看哪几列。
- 行为：
  - 工具栏“一键分析”，点一下自动出 3–5 张柱状图。
  - 分组列优先按“区域、城市、省份、渠道、产品、状态、类型、类别、等级、分组”等词挑，再用“去重不超过 50”过滤。
  - 度量列优先“金额、销售额、数量、单价、成本、毛利、收入”，没有就取第一个数值列。
  - 结果区竖排展示，顶部写明自动选了哪几列。
- 验收：
  - [x] 区域、城市、渠道、金额四列的表，一键出三张图（离屏截图 /tmp/auto-analysis.png 三张竖排；10 万行真实文件端到端至少 3 张）
  - [x] 订单号这种高基数列不会成为分组列（断言：订单号去重 100 时被跳过，候选只剩区域与渠道）
  - [x] 328 万行文件上一键分析整体 3 秒内（release 实测 0.22 秒出 5 张图）
  - [x] 结果只属于当前文件：关掉文件或切到另一个文件后，上一份的图不再显示（2026-10-26 真机验证，截图 `docs/media/verification/close-file-after.png` 与 `switch-file-after.png`）
- 边界：不做相关性分析、异常检测和自动结论文字。
- 依赖：R-VIZ-01
