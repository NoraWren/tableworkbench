# 术语表

| 术语 | 含义 |
|---|---|
| 块（block） | 表格按 5000 行切出的一段数据，一次查询取一块，界面按块渲染 |
| 虚拟滚动 | 只渲染可见行，滚出去的行不占视图，靠数据源按需取数 |
| Parquet 缓存 | 首次导入时把 CSV/Excel 转成的列式文件，放在应用支持目录，下次直接读 |
| 只读连接 | DuckDB 连接以只读方式打开，物理上拒绝写操作 |
| 临时表 | 会话内有效、不落盘的表或视图，关闭应用即消失 |
| 基数（cardinality） | 一列里不同值的数量，决定透视和分组结果会不会爆炸 |
| 下推（pushdown） | 把排序、筛选、聚合翻译成 SQL 交给数据库做，Swift 侧不参与计算 |
| 冷启动 | 从点击图标到窗口可交互 |
| 首屏 | README 打开后不解屏能看到的部分 |
| 放行门槛 | 里程碑里必须达成才能继续投入的硬性条件 |
| GB18030 | GBK 的超集，覆盖中文常用字符，国内 CSV 导出的常见编码 |
| view-based NSTableView | AppKit 现代表格模式，按需创建并复用单元格视图 |
| NSViewRepresentable | SwiftUI 里包一层 AppKit 视图的协议 |
| @Observable | Observation 框架的宏，用于状态层，替代 ObservableObject |
| 模型配置 | 一组 Base URL、模型 ID、密钥和参数的组合，可存多份，设一个默认 |
| 样本行 | 发给模型的少量数据行，默认 20 行，均匀采样，不取前 N 行 |
| 打码 | 发送前把身份证、手机号、银行卡、邮箱等值替换成保留格式的掩码 |
| 提示注入 | 把指令藏进数据里，诱导模型执行危险操作；本项目在提示和解析两层防 |
| 上下文预算 | 单次请求允许发送的最大体积，默认 32 KB |
| 首 token 时延 | 从发送请求到界面上出现第一个字符的时间 |

## 数字口径

所有性能数字的口径统一如下，避免同一句话有两种解读。

| 数字 | 从哪算到哪 |
|---|---|
| 打开耗时 | 文件松手那一刻，到表格第一次能滚动 |
| 冷启动 | 进程启动，到窗口可交互 |
| 包体积 | GitHub Releases 上的 dmg 文件大小 |
| 排序耗时 | 点击列头，到新顺序的第一屏绘制完成 |
| 筛选耗时 | 条件输入最后一个字符，到行数更新 |
| 查询耗时 | 按 Command+R，到结果第一屏绘制完成 |

机器口径：M1 或更新、16 GB 内存以上、Apple 内建 SSD。低于这个配置的数字不用写进 README。
