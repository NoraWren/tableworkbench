# 09 应用外壳

## R-SHELL-01 窗口结构

- 优先级：P1
- 状态：已定义
- 行为：三栏加一条底栏，用 NavigationSplitView 实现。
  - 左栏：已打开的文件、表、保存的查询。可折叠。
  - 中栏：数据网格，顶部工具栏，底部 SQL 抽屉。
  - 右栏：列检查器，可折叠，宽度可拖。
  - 窗口最小尺寸 900 × 600。
- 验收：
  - [ ] 两个侧栏都能用菜单和快捷键折叠，折叠后中栏自动占满
  - [ ] 窗口拖到 900 × 600 时不出现控件重叠或文字截断
  - [ ] 退出再打开，侧栏折叠状态和窗口尺寸都恢复
- 边界：不做多窗口、不做标签页。
- 依赖：R-GRID-01

## R-SHELL-02 菜单与快捷键

- 优先级：P1
- 状态：已定义
- 行为：
  - File：Open（Command+O）、Export（Command+Shift+E）、Close File（Command+W）。
  - Edit：Copy（Command+C）、Find（Command+F 聚焦筛选输入框）。
  - View：Show/Hide Sidebar（Control+Command+S）、Show/Hide Inspector（Command+Option+I）、Show/Hide SQL（Command+J）、Toggle Dark Mode 跟随系统。
  - Query：Run（Command+R）、Cancel（Command+.）、New Query（Command+N）。
  - Help：文档链接、报告问题。
- 验收：
  - [ ] 所有菜单项都有快捷键，且不与其他系统快捷键冲突
  - [ ] 无可执行内容时，菜单项置灰而不是点了没反应
- 边界：不做自定义快捷键设置。
- 依赖：R-SHELL-01

## R-SHELL-03 深色模式与外观

- 优先级：P1
- 状态：已定义
- 行为：跟随系统外观，不提供应用内独立开关。所有自绘内容（直方图、条形图、空值标记）都从系统语义色取色，不写死十六进制。
- 验收：
  - [ ] 系统切换深色浅色，应用内无残留白底或黑字
  - [ ] 深色模式下表格分隔线可见但不过重
- 边界：不做自定义主题。
- 依赖：R-INSP-03

## R-SHELL-04 空状态与引导

- 优先级：P1
- 状态：已定义
- 行为：
  - 没有任何文件时，中栏显示一个大号拖放区域，一句话说明支持哪些格式。
  - 不弹欢迎向导，不做多步引导。
  - 拖放区下方给一行小字：数据不出本机。
- 验收：
  - [ ] 首次启动到能拖入文件不超过一次点击
  - [ ] 空状态在最小窗口尺寸下排版正常
- 边界：不做示例数据集自动下载。
- 依赖：R-IMP-01

## R-SHELL-05 错误与状态提示

- 优先级：P1
- 状态：已定义
- 行为：
  - 长任务（导入、转换、导出、大查询）在状态栏给一行进度，不弹模态框。
  - 只有需要用户决策时才弹窗，比如"这个透视结果有 80 万行，继续吗"。
  - 报错统一用同一种卡片样式：一句话结论、可展开的详情、一个主要动作按钮。
- 验收：
  - [ ] 所有错误路径都走同一个组件，不出现两种风格的报错
  - [ ] 进度提示在任务结束后自动消失
- 边界：不做错误码体系。
- 依赖：R-IMP-07

## R-SHELL-06 文件与数据安全提示

- 优先级：P1
- 状态：已定义
- 行为：
  - 应用不主动联网。唯一的网络行为是 DuckDB 扩展下载，且必须在设置里显式开启。
  - 首次使用扩展时弹一次说明，讲清要下载什么、从哪下载。
  - 设置页有一行"当前会话没有访问网络"，让用户能确认。
- 验收：
  - [ ] 断网时核心功能（CSV、Parquet、SQL、导出）全部可用
  - [ ] 未开启扩展下载时，抓包看不到应用的出站请求
- 边界：不做代理设置界面，跟随系统代理。
- 依赖：R-IMP-06、R-REL-05

## R-SHELL-07 设置窗口

- 优先级：P1
- 状态：已定义
- 场景：用户要改缓存上限、配 AI 模型、清理本地数据。
- 行为：Command+, 打开设置。v0.1 三个页签，v0.2 增加第四个。
  - 通用：缓存上限、默认导出格式、是否复制表头。
  - 隐私：清除缓存、显示当前网络状态。
  - 关于：版本号、许可证、问题反馈链接。
  - AI 模型（v0.2 增加）：配置列表与表单，细节见 R-AI-02。
- 验收：
  - [ ] 设置改动即时生效，不需要重启应用
  - [ ] 设置窗口尺寸和最后停留的页签在重启后恢复
  - [ ] 未配置 AI 时，AI 页签显示"未配置"，不是空白页
- 边界：不做账号登录、不做同步。
- 依赖：R-IMP-05、R-AI-02（v0.2 的 AI 页签）
