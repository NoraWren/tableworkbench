# 09 应用外壳

## R-SHELL-01 窗口结构

- 优先级：P1
- 状态：已定义
- 行为：三栏加一条底栏，用 NavigationSplitView 实现。
  - 左栏：已打开的文件、表、保存的查询。可折叠。
  - 中栏：数据网格，顶部工具栏，底部 SQL 抽屉。
  - 右栏：列检查器，可折叠，宽度可拖。
  - 窗口最小尺寸 900 × 600。
- 验收：
  - [ ] 两个侧栏都能用菜单和快捷键折叠，折叠后中栏自动占满
  - [ ] 窗口拖到 900 × 600 时不出现控件重叠或文字截断
  - [ ] 退出再打开，侧栏折叠状态和窗口尺寸都恢复
- 边界：不做多窗口、不做标签页。
- 依赖：R-GRID-01

## R-SHELL-02 菜单与快捷键

- 优先级：P1
- 状态：已完成
- 行为：
  - File：Open（Command+O）、Export（Command+Shift+E）、Close File（Shift+Command+W）。
  - Edit：Copy（Command+C）、Find（Command+F 聚焦筛选输入框）。
  - View：Show/Hide Sidebar（Control+Command+S）、Show/Hide Inspector（Command+Option+I）、Show/Hide SQL（Command+J）。
  - Query：Run（Command+R）、Cancel（Command+.）、New Query（Command+N）。
  - Help：文档链接、报告问题。
- 验收：
  - [x] 所有菜单项都有快捷键，且不与其他系统快捷键冲突
  - [x] 无可执行内容时，菜单项置灰而不是点了没反应
- 边界：不做自定义快捷键设置。
- 依赖：R-SHELL-01

说明：

- Close File 用 Shift+Command+W。Command+W 留给系统关窗口，替换会破坏习惯，见 \`openspec/changes/archive/\` 下 add-app-menu-bar 的 D3。
- 不做 Toggle Dark Mode 菜单项。外观跟随系统，应用内不提供独立开关，见 R-SHELL-03。
- Help 菜单（文档链接、报告问题）要等仓库公开、有 issue 地址之后才做，见 R-REL 发布相关条目。
- 菜单项与快捷键集中写在 \`app/Sources/WorkbenchUI/MenuCatalog.swift\`，测试断言每项都带 Command、组合不重复、置灰状态随文件走。
- 2026-10-26 逐条实测：11 项的键位用辅助功能属性读出来，与设计一致；菜单点击和快捷键两条路都过了一遍。⌘O、⌘J、⌃⌘S、⌥⌘I 用全屏合成按键；⇧⌘E、⇧⌘W、⇧⌘A、⌘R、⌘N、⌘F 改为直接投递给应用进程，因为本机前台常被浏览器与输入法切走，全屏合成的 Shift 组合会先被它们吃掉，与应用侧无关。

## R-SHELL-04 空状态与引导

## R-SHELL-05 错误与状态提示

- 优先级：P1
- 状态：已定义
- 行为：
  - 长任务（导入、转换、导出、大查询）在状态栏给一行进度，不弹模态框。
  - 只有需要用户决策时才弹窗，比如"这个透视结果有 80 万行，继续吗"。
  - 报错统一用同一种卡片样式：一句话结论、可展开的详情、一个主要动作按钮。
- 验收：
  - [x] 所有错误路径都走同一个组件，不出现两种风格的报错（导入失败、SQL 失败、取块失败一律落到 `model.error`，界面只有一处 `ImportErrorCard`；`rg ImportErrorCard` 全仓只有定义与那一个使用点）
  - [x] 进度提示在任务结束后自动消失（`isQuerying` / `isRunningSQL` / `isExporting` 在各自的完成与失败分支里都会复位，界面的转圈与「停止」按钮跟着这三态走；取消千万行物化后实测转圈一秒内消失）
- 边界：不做错误码体系。
- 依赖：R-IMP-07

## R-SHELL-06 文件与数据安全提示

- 优先级：P1
- 状态：已定义
- 行为：
  - 应用不主动联网。唯一的网络行为是 DuckDB 扩展下载，且必须在设置里显式开启。
  - 首次使用扩展时弹一次说明，讲清要下载什么、从哪下载。
  - 设置页有一行"当前会话没有访问网络"，让用户能确认。
- 验收：
  - [ ] 断网时核心功能（CSV、Parquet、SQL、导出）全部可用
  - [ ] 未开启扩展下载时，抓包看不到应用的出站请求
- 边界：不做代理设置界面，跟随系统代理。
- 依赖：R-IMP-06、R-REL-05

## R-SHELL-07 设置窗口

- 优先级：P1
- 状态：已定义
- 场景：用户要改缓存上限、配 AI 模型、清理本地数据。
- 行为：Command+, 打开设置。v0.1 三个页签，v0.2 增加第四个。
  - 通用：缓存上限、默认导出格式、是否复制表头。
  - 隐私：清除缓存、显示当前网络状态。
  - 关于：版本号、许可证、问题反馈链接。
  - AI 模型（v0.2 增加）：配置列表与表单，细节见 R-AI-02。
- 验收：
  - [ ] 设置改动即时生效，不需要重启应用
  - [ ] 设置窗口尺寸和最后停留的页签在重启后恢复
  - [ ] 未配置 AI 时，AI 页签显示"未配置"，不是空白页
- 边界：不做账号登录、不做同步。
- 依赖：R-IMP-05、R-AI-02（v0.2 的 AI 页签）
