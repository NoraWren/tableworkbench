## 每条需求的格式

```
## R-IMP-05 Parquet 缓存

- 优先级：P0
- 状态：待实现
- 场景：一句话说明用户在哪一步遇到它
- 行为：实现后用户看到什么、系统做什么（可用编号列表）
- 验收：
  - [ ] 可勾选的具体检查项，尽量带数字
- 边界：明确不做什么
- 依赖：关联的其他编号
```

验收项必须能被第三方复现。写"响应快"不算，写"1000 万行文件打开到可交互不超过 1 秒"才算。
