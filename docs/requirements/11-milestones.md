# 11 里程碑

排期按"一个人全职、此前没写过 Swift"来算，共 12 周。两个人可以压到 6 到 7 周，但前提是其中一人已能独立写 SwiftUI。

## R-MS-01 前置条件

- 优先级：P0
- 状态：待验证
- 行为：正式开工前必须全部就绪。
  - Xcode 安装完成，xcodebuild -version 有输出。
  - Apple Developer 账号已申请（审批可能耗时，先交钱排队）。
  - 网络能拉到 SPM 依赖（GitHub 直连在这台机器上不稳定，需代理）。
  - 产品名与 Bundle ID 已定（R-DEC-06）。
- 验收：
  - [ ] xcodebuild -version 有输出
  - [ ] swift build 能拉下 duckdb-swift 并编译通过
  - [ ] 签名证书在钥匙串里可见
- 边界：这一条不完成，后面所有周计划都不成立。
- 依赖：R-DEC-04、R-DEC-06

## R-MS-02 第 1–2 周：技术验证

- 优先级：P0
- 状态：待验证
- 行为：目标只有一个，证明这条路能走通。做一个最小应用：能拖入 CSV，走 DuckDB 查出来，用 NSTableView 显示前 5000 行。
- 验收：
  - [ ] 拖入 500 MB CSV 到看到数据不超过 3 秒（这阶段允许比目标慢）
  - [ ] 滚动 10 万行的测试表不掉帧
  - [ ] 关闭应用后进程退出干净，无残留内存
- 放行门槛：这三条过不了，先换方案再往下投入，别硬撑。
- 边界：这两周不做筛选、不做 SQL 抽屉、不做检查器。
- 依赖：R-MS-01、R-GRID-01、R-IMP-01
